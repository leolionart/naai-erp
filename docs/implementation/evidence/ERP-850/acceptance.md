# ERP-850 Acceptance

- [ ] Every canonical resource is included or explicitly classified in the manifest.
- [ ] XLSX preserves editable exact values, stable identities, versions and relationships.
- [ ] Unchanged export/import is a zero-mutation no-op.
- [ ] Dry-run reports row-level diffs and errors before commit.
- [ ] Commit is authorized, audited, version-checked and retry-idempotent.
- [ ] Posted/issued history is immutable and corrected only through lifecycle services.
- [ ] Financial and operational controls reconcile after import.
