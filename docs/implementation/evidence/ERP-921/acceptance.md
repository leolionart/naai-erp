# ERP-921 acceptance

- [ ] Customer/supplier, project, category and description are editable in one action.
- [ ] Backend resolves compatible canonical relationships without multi-API client orchestration.
- [ ] Ambiguous matches create no mutation and return structured field errors.
- [ ] Drafts update with version, audit and idempotency controls.
- [ ] Posted history remains immutable and correction creates linked reversal/replacement.
- [ ] Web, REST and CLI use the same application service.
