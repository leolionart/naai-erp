# ERP-810 Risks

- Some critical OpenAPI operations still lack fully typed request/response schemas. The relationship
  manifest and guide close the ingestion knowledge gap, but OpenAPI schema enrichment remains a
  useful future hardening task.
- Known unavailable operations remain listed in the manifest and must not be called.
- Generic evidence, project-cost source and workbook proposal links are application-validated rather
  than physical foreign keys; clients must perform canonical API readback.
- Tax and dimension compatibility remains policy/date dependent. The guide requires lookup and
  validation but does not replace accountant review.
