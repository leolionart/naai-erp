# ERP-873 summary

The owner-current read model now exposes canonical expense and purchase-invoice
sources linked through the posted journal. The web workspace shows what the
owner paid for, the payee, category, expense class, CIT/VAT states, and a direct
link to the source expense or purchase invoice while retaining journal
drill-down.

Balances remain derived only from posted ledger lines. Source metadata is
descriptive traceability and does not change owner-current calculations.
