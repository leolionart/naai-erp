# ERP-917 acceptance checklist

- [x] Authorized users can page and filter background activity by service, status and severity.
- [x] Organization isolation and operations/read authorization are enforced.
- [x] Secrets, tokens, raw evidence and complete financial payloads are redacted.
- [x] Default 30-day retention is configurable and visible in the viewer.
- [x] Cleanup is bounded/retry-safe and preserves immutable accounting/audit/outbox records.
- [x] Sidebar navigation opens the viewer with loading, empty and error states.
