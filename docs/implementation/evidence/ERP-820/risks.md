# ERP-820 Risks

- Owner reimbursement and customer-money custody/clearing remain missing first-class product
  capabilities, not merely documentation gaps.
- The owner personal account must not be imported as a company financial account; reviewed manual
  clearing may still be required until dedicated APIs exist.
- Commercial/expense runtime does not yet enforce every project/customer/dimension lookup described
  by AI preflight rules.
- Owner capital-versus-loan treatment remains an owner/accountant decision. Advanced petty-cash and
  accountable-advance workflows are outside the default operating model.
