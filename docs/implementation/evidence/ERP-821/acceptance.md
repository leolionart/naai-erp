# ERP-821 Acceptance

- [x] Company-to-owner withdrawals are explicitly not operating expenses.
- [x] Owner-paid supplier invoices and expenses retain supplier/payee/project identity.
- [x] Owner-to-company funding is explicitly not revenue.
- [x] Large-invoice settlement after owner funding does not duplicate funding or expense.
- [x] Reimbursement clears the owner balance and does not create a second expense.
- [x] AI is forbidden from guessing owner loan/equity/current-account classifications or codes.
- [x] Machine-readable activity IDs and an ingestion recipe describe the full cycle.
