# ERP-859 acceptance

- Invoice and expense forms no longer expose a separate contract field.
- The project dropdown is sourced from canonical project master data.
- Selecting a sales project sets its canonical customer relationship.
- Project list tables display the project relationship without a duplicate contract column.
- Project profiles present contract facts as part of the project and distinguish contract value from
  approved budget.
- Existing multi-contract project data is not silently collapsed.
