# Operational runbooks

MVP runbooks cover Compose startup, migrate-once, workbook import and manual rollback to an immutable SHA image. Backup/restore design remains reference material; a formal restore-drill program is outside the active MVP ledger.

These runbooks explain how to operate the platform rather than how to perform accounting work. For
the user journey and business-module handoffs, see the
[overall business workflow guide](../product/business-workflows.md). Use the workflow guide to
identify the business step first, then use the relevant runbook here for deployment, recovery or
maintenance procedures.
